BINZ ACCOUNTING APP
====================

This folder is the organized working copy for the Binz Accounting App.

Folders
-------
app\              Active Electron source and local test landing page.
app-data\         Local application data, including UUID state.
electron-runtime\ Packaged Electron runtime files.
installer\        Active installer scripts, configuration, and latest setup EXE.

Run the local test build
------------------------
From PowerShell:
  .\RUN-LOCAL-TEST.ps1

The test build is local-only: auto-update is disabled and external HTTP, HTTPS,
WebSocket, and secure WebSocket requests are blocked.

Latest installer
----------------
  installer\BinzAccountingAppSetup-1.0.0.exe
